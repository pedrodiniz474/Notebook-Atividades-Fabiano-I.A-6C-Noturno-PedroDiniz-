## Sobre este repositório

Este repositório reúne todos os notebooks desenvolvidos ao longo da disciplina. As atividades foram feitas no Google Colab e enviadas para cá em formato `.ipynb`, contendo o código, os comentários explicando cada etapa e as saídas geradas na execução.

A cada nova entrega de atividade, uma **release** é criada neste repositório com a data correspondente à entrega.

## Como executar os notebooks

1. Abra o arquivo `.ipynb` desejado.
2. Clique em "Open in Colab" (ou faça o upload manual do arquivo no [Google Colab](https://colab.research.google.com/)).
3. Execute as células na ordem em que aparecem, de cima para baixo.
